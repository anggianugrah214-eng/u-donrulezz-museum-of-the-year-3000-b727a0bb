A make.fun entry for [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb): a Node program (`main.ts`) that writes one line to `/output/entry.txt` — the museum label a museum in the year 3000 puts beside an ordinary object from today.

The label, on a self-checkout machine:

> Self-Checkout Machine, c. 2024. Shoppers performed the cashier's job unpaid, then were tried by the machine for an unexpected item in the bagging area.

Run it with Node 22.18+: `node main.ts`, then read `/output/entry.txt`.
